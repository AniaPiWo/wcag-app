# Font Directory

## Required Font Files

Please add the Roboto font files to this directory with the following structure:

```
public/fonts/
  Roboto/
    Roboto-Regular.ttf
    Roboto-Bold.ttf
    Roboto-Italic.ttf
```

You can download the Roboto font family from Google Fonts:
https://fonts.google.com/specimen/Roboto

After downloading, extract the font files and place them in the appropriate directories.
